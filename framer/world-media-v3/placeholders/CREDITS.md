# Placeholder videos for the globe

Stand-ins for the globe's fifteen tiles until World Media's own videos are added in the
**Globe media** field in Framer. Each clip is cut from a Mixkit stock video: 5.5 seconds,
cropped to its tile's shape, looped with a half-second crossfade, no sound. Each comes as
WebM (VP9) and MP4 (H.264), so every browser can play one of them.

The site loads these files from jsDelivr, pinned to the commit that added them, so later
changes to this folder never alter the live site.
